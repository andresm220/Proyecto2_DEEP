> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar listo el pipeline de datos y entrenamiento de la DCGAN (base, hinge, final) con el que Persona B evalúa y genera la galería, más la documentación de Persona A (notebook de datos, notebook de Colab, README, figuras para diapositivas).

**Architecture:** Paquete `src/` ejecutable como módulos (`python -m src.train --config ...`). Cada run lo define un YAML en `configs/`; los experimentos heredan de `base.yaml` con `inherit:` y cambian una sola clave. Todo lo que produce un run va a `<out-root>/runs/<name>/` (en Colab, `out-root` está en Google Drive). Los tests corren en CPU con pocas iteraciones; el entrenamiento real se hace en una GPU T4 de Colab.

**Tech Stack:** Python 3.12, PyTorch 2.10 / torchvision 0.25, NumPy, Matplotlib, PyYAML, Pillow, pytest, nbformat/nbconvert.

**Spec:** `proyecto2_gan_plan.md` (secciones 0, 2, 3, 4, 5, 6-Persona A, 7, 8)

## Global Constraints

- Ninguna imagen sale de un generador externo; todo sale de nuestro G.
- Experimentos: **una sola diferencia** con `base` (mismos datos, semilla 42, épocas y `fixed_noise.pt`).
- Hipótesis escrita en el notebook **antes** de entrenar cada experimento, con fecha y hora.
- Datos normalizados a [−1, 1]; reescalado de pixel art siempre con `NEAREST`.
- Checkpoint: `{"G","D","optG","optD","epoch","config"}` (se permiten claves extra) + `last.pt`.
- `losses.csv`: columnas exactas `epoch, iter, loss_D, loss_G, D_x, D_G_z`.
- Ruido fijo: `torch.manual_seed(1234); torch.randn(16, 100, 1, 1)` → `outputs/fixed_noise.pt`, compartido por todos los runs.
- Generar siempre con `G.eval()`.
- `train.py --resume` reanuda desde `last.pt`.
- Semillas: global 42, ruido fijo 1234, galería 0–199.
- Comentarios: explicar en 1–3 líneas cada decisión no obvia.

def test_eval_generation_independent_of_batch():
    torch.manual_seed(0)
    G, _ = build_models(load_config("configs/base.yaml"))
    G.train(); G(torch.randn(64, 100, 1, 1))  # actualiza running stats de BN

    with torch.no_grad():

```python
"""Figuras comparativas entre runs (mismo ruido fijo): rejillas lado a lado y curvas superpuestas.

    python -m src.compare --runs base exp_hinge --out outputs/figs/cmp_base_vs_hinge
"""
import argparse
from pathlib import Path

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
from PIL import Image

from .utils import moving_average, read_losses


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--runs", nargs="+", required=True)
    ap.add_argument("--out-root", default="outputs")
    ap.add_argument("--out", required=True, help="prefijo de salida (sin extensión)")
    ap.add_argument("--window", type=int, default=50)
    args = ap.parse_args()
    runs = Path(args.out_root) / "runs"
    Path(args.out).parent.mkdir(parents=True, exist_ok=True)

    fig, axes = plt.subplots(1, len(args.runs), figsize=(4 * len(args.runs), 4.3), dpi=150)
    for ax, name in zip(np.atleast_1d(axes), args.runs):
        ax.imshow(Image.open(runs / name / "fixed_grid.png"), interpolation="nearest")
        ax.set_title(name)
        ax.axis("off")
    fig.suptitle("Mismo ruido fijo (fixed_noise.pt), última época")
    fig.tight_layout()
    fig.savefig(f"{args.out}_grids.png")
    plt.close(fig)

    keys = [("loss_D", "Pérdida D"), ("loss_G", "Pérdida G"), ("D_x", "D(x)"), ("D_G_z", "D(G(z))")]
    fig, axes = plt.subplots(1, 4, figsize=(18, 3.8), dpi=150)
    for name in args.runs:
        d = read_losses(runs / name / "losses.csv")
        for ax, (k, title) in zip(axes, keys):
            ma = moving_average(d[k], args.window)
            ax.plot(np.arange(len(d[k]) - len(ma), len(d[k])), ma, label=name)
            ax.set_title(title)
            ax.set_xlabel("iteración")
            ax.grid(alpha=0.3)
    axes[0].legend()
    fig.tight_layout()
    fig.savefig(f"{args.out}_curves.png")
    plt.close(fig)


if __name__ == "__main__":
    main()
```
